# Renovate

A static, interactive 3D renovation demo. Open the published site in a modern browser with WebGL support.

The public demo uses privacy placeholders in place of personal reference photographs and artwork.

The deployment files are served directly from the repository root. Third-party license terms are retained in [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt); the referenced Three.js files are in `assets/`.
